# Multiplayer

Farbound works in multiplayer, on your own server or on a community server. Server use is explicitly allowed, see [[License and Credits]].

## Joining a server

- Your pack version has to **match the server's version**. If you cannot join or get a mod mismatch message, update (or ask the server owner which version is current).
- Install the pack the usual way, including the quest mods from the first-launch screen, see [[Installation]]. Do not add client mods without checking with the server first.
- Give your instance enough RAM, see [[Performance and Settings]].

## What works together

| Feature | How it works |
|---|---|
| **Quests** | Progress is shared within your team via FTB Teams. Create or join a team to progress together. |
| **Loot** | Structure loot is instanced (Lootr). Everyone opens their own version of each chest. |
| **Voice chat** | Simple Voice Chat gives proximity voice if the server runs the matching server mod and the voice port is open. Pairs wonderfully with shouting orders across an airship deck. |
| **Pings** | Point at things without typing. |
| **Shared vessels** | Friends can walk around on your airship, ship or train while it moves, and seats can be bolted on. |

## Running your own server

- Use the **server pack** matching the client version, and the same pack version on all clients.
- The server needs the **quest mods** too. Download them once and put them into the server's `mods` folder.
- Allocate generous memory and keep an eye on TPS. Physics contraptions are CPU intensive.
- Client-only mods must not go into the server's `mods` folder.
- Voice chat needs its UDP port reachable from outside if you want it to work.
- Back up your world regularly and before every pack update.

## Good manners with contraptions

Physics vessels are the most expensive thing in the pack. On shared servers, these habits keep it fun for everyone:

- Keep vessels as small as they need to be.
- Park vehicles in one place instead of leaving them scattered across the map.
- Use chunk loaders sparingly, and only where the server rules allow them.
- Follow the rules of your server, they come before anything written here.
